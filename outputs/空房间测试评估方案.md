# 空房间测试评估方案（A/B/C/D 版）

## 1. 评估目标
本轮测试的核心不是单纯判断图片是否更好看，而是判断结果是否仍然忠实表达原始空间事实。

评估优先级建议为：
1. 是否影响事实表达
2. 是否出现结构、物体、材质、颜色、光影错误
3. 如果有变化，这种变化是否无伤大雅

## 2. 四个等级定义

### A 级：基本正确
定义：基本没有明显问题，材质、颜色、结构、光影都与原图一致，或只有轻微优化。

### B 级：轻微变化，但无所谓
定义：有局部变化，但不重要，不会误导判断。
典型情况：本来就有装饰的位置又多了一点装饰，局部更亮一点，但不影响整体理解。

### C 级：有变化，但不影响事实表达
定义：能明显看出与原图不同，但仍然不影响对空间、材质、结构真实情况的判断。
典型情况：颜色略深、反光稍重、材质观感有偏差，但事实没有被改错。

### D 级：严重错误
定义：已经影响事实表达，属于明确 bad case。
典型情况：材质改错、颜色严重失真、凭空多出灯/柜子/把手、错误光斑、墙变柜子、水槽变色等。

## 3. 四个专项维度

1. 材质色差
2. 材质品类变化
3. 光影过强
4. 结构与物品变化

## 4. 统计口径
本轮汇总建议统一使用以下口径：

- `A/B/C = 通过`
- `D = 不通过`

也就是说，只要结果虽然有变化，但仍然不影响事实表达，就仍然视为通过；只有严重错误才记为 bad case 失败样本。

## 5. 推荐标注字段

- `scene_id`
- `test_set`
- `file_name`
- `grade`：A/B/C/D
- `primary_dimension`
- `issue_type`
- `issue_desc`
- `factual_impact`
- `confidence`
- `note`

## 6. 问题类型建议

- `结构幻觉`
- `物体幻觉`
- `错误光源`
- `过曝`
- `反光异常`
- `颜色偏移`
- `材质漂移`
- `细节丢失`
- `过度增强`
- `局部可接受变化`

## 7. 实操判断方法
每张图判断时，只需要问四个问题：

1. 有没有凭空多出结构、物体、灯具、柜子、把手？
2. 有没有明显材质或颜色被改错？
3. 有没有不合理光斑、反光、过曝？
4. 即使有变化，是否仍然不影响事实表达？

建议判断规则：
- 如果只是轻微变化且无所谓，判 `B`
- 如果变化明显但仍不影响真实表达，判 `C`
- 只有明显影响事实表达时，才判 `D`
